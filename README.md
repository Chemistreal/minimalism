# minimalism — 미니멀리즘 레벨 테스트

버전이 다섯 벌 있고, **서로 이어지는 링크가 없다.** 어느 것이 지금 쓰는
판인지 파일만 봐서는 알 수 없어서, 재어 본 것을 적어 둔다.

| 파일 | 제목 | 크기 | 무엇 |
|---|---|---|---|
| `index.html` | 미니멀리즘 레벨 테스트 | 33KB | 검사 + 결과 |
| `pro.html` | … PRO | 33KB | 검사 + 결과 |
| `final.html` | … FINAL | 37KB | 검사 + 결과 |
| `premium/index.html` | … PREMIUM | 5KB | 결과 리포트만 |
| `v2/index.html` | … PREMIUM V2 | 6KB | 결과 리포트만 |

- 저장소 기록이 **커밋 하나뿐**이라(2026-05-14) 어느 것이 최신인지 기록으로는
  가릴 수 없다.
- 세 벌(`index`·`pro`·`final`)은 같은 이름의 함수를 여럿 갖고 있는데
  **내용이 서로 다르다**(36개 중 28개). 점수 내는 `compute` 도 셋이 다르다 —
  판이 이어지는 관계이지 서로 맞춰야 하는 사본이 아닌 것으로 보인다.
  ⚠ 그래서 **일부러 검사로 묶지 않았다.** 사본이어야 하는 것이라면 알려 달라.

## 검사

```
python3 tools/audit_pages.py
```

색 대비·글씨 크기·`viewport`·제목 단계·표 머리·깨진 링크를 잰다. 하위 폴더
(`premium/`·`v2/`)까지 본다 — 위층만 보면 그 둘은 아무도 안 재는 화면이 된다.
